Synchronisation Cloud

Les comptes et les sillons sont sauvegardés en ligne (Netlify) et accessibles depuis n'importe quel appareil.

—

Les modifications sont synchronisées toutes les 5 secondes. Connectez-vous séparément sur chaque appareil.

API — SNCK Connect (connexion requise)

Les sillons du réseau sont accessibles en lecture après connexion sur ce site. L’API retourne leurs horaires, retards et statuts enregistrés.

—

Exemple après connexion sur ce site :

fetch('/api/sillons')
  .then(r => r.json())
  .then(sillons => console.log(sillons));

Cette API renvoie les sillons et leurs informations. Une session connectée est nécessaire ; aucun mot de passe n’est exposé.
